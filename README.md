# 🛍️ Shopper Spectrum  
### Customer Segmentation & Product Recommendation System  

## 📌 Project Overview
Shopper Spectrum is a Machine Learning-powered retail analytics application that performs:

- 👤 Customer Segmentation using RFM Analysis + KMeans Clustering
- 🛒 Product Recommendation using Cosine Similarity
- 📊 Interactive Web App built with Streamlit

This project helps businesses:
- Identify high-value customers
- Detect at-risk customers
- Recommend similar products
- Improve targeted marketing strategies

---

## 🧠 Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Streamlit
- Cosine Similarity
- KMeans Clustering

---

## 📊 Machine Learning Models

### 1️⃣ Customer Segmentation
- RFM (Recency, Frequency, Monetary) Analysis
- StandardScaler for feature scaling
- KMeans clustering for segmentation

### 2️⃣ Product Recommendation
- Customer-product pivot matrix
- Cosine similarity matrix
- Top-N similar product recommendations

---

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/your-username/shopper-spectrum.git
cd shopper-spectrum
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run Streamlit app:

```bash
streamlit run app.py
```
